# JobReady

Тренажёр собеседований с AI-интервьюером.

```
JobReady/
  frontend/   Next.js — веб-приложение (десктоп, планшет, телефон)
  backend/    FastAPI — API, база данных, GigaChat
```

Как запустить фронтенд — в [frontend/README.md](frontend/README.md), бэкенд — в [backend/README.md](backend/README.md).

Открывать в VS Code лучше всю папку `JobReady` — рекомендованные расширения подскажет сам редактор.
