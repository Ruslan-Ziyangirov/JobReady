# JobReady — фронтенд

Тренажёр собеседований с AI-интервьюером. Первая версия интерфейса по макетам из Figma (десктоп 1440, планшет 768, телефон 375). Бэкенда пока нет — все данные берутся из `lib/mock-data.ts`.

## Запуск

Нужен Node.js 20.9+ (проверено на 24).

```bash
npm install
npm run dev
```

Открыть http://localhost:3000 — откроется экран входа. Любое имя, номер из 10 цифр и любой 4-значный код пропускают дальше.

Другие команды:

- `npm run build` — продакшн-сборка
- `npm run start` — запуск собранной версии
- `npm run lint` — проверка ESLint

## Стек

- **Next.js 16** (App Router, Turbopack) + **React 19** + **TypeScript**
- **Tailwind CSS 4** — токены дизайна в `app/globals.css` (`@theme`)
- **lucide-react** — иконки
- Шрифт Inter (латиница + кириллица) через `next/font`

| Маршрут | Экран |
|---|---|
| `/login` | Вход: имя и телефон |
| `/login/code` | Код из SMS |

| `/results` | Результаты и разбор вопросов |

| `/plan/day` | День подготовки: список проблем |
| `/plan/topic` | Проработка темы |
| `/plan/topic/result` | Результат проработки |
| `/history` | История интервью |

## Структура

```
app/
  (auth)/          экраны входа — без сайдбара
  (app)/           экраны приложения — с сайдбаром / мобильной шапкой
  globals.css      токены цветов, радиусов, засветов
components/
  layout/          AppShell: сайдбар (от 1024px), шапка и выезжающее меню (до 1024px)
  ui/              кнопки, чипсы, карточки, полосы оценок, чек-листы
  auth/ onboarding/ interview/ results/ plan/   части конкретных экранов
lib/
  types.ts         типы домена — под будущие схемы FastAPI
  mock-data.ts     мок-данные
  api.ts           единая точка доступа к данным
public/illustrations/   3D-иллюстрации из UI-кита Figma
```

## Брейкпоинты

- до 768px — телефон: одна колонка, шапка с бургер-меню
- 768–1023px — планшет: сетки в 2–3 колонки, шапка с бургер-меню
- от 1024px — десктоп: сайдбар слева, двухколоночные экраны

## Подключение бэкенда (FastAPI)

1. Скопировать `.env.example` в `.env.local` и указать `NEXT_PUBLIC_API_URL` (например, `http://localhost:8000`).
2. В `lib/api.ts` уже описаны функции с путями API — при заданном адресе они ходят в бэкенд, без него возвращают моки.
3. Вход по SMS уже ходит в бэкенд (`auth` в `lib/api.ts`), сессия — httpOnly-cookie. Код при разработке печатается в консоль бэкенда.
4. Интервью тоже идёт через бэкенд: ответы интервьюера приходят потоком (`interviews.answer` в `lib/api.ts`, хук `components/interview/use-interview.ts`).
5. Ещё не подключено (помечено `TODO`): оценка ответа на тему; разбор интервью и план пока на моках.
